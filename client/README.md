# ChatApp client

The browser client is built with Vue 3, TypeScript, and Vite. The root package scripts start the client with the Express and Socket.IO server, build the server and client, and run the backend security suite.

The client preserves the existing REST and Socket.IO interfaces. It includes English and Arabic layouts, direct and group chats, authenticated image/PDF attachments, WebRTC calls, and the shared PDF whiteboard.
